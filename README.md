# Ômega · atualizações do app

Pacotes do app Ômega Gestão já montados, baixados pelo próprio app instalado no celular (atualização automática).
Não há código-fonte, senhas nem chaves aqui: só o mesmo conteúdo que o site do Ômega já entrega a quem o abre.

- `atualizacao.json`: a versão mais nova, o arquivo e a conferência (sha256).
- `pacotes/<versão>.zip`: o app montado.
